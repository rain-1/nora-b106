# Backplane source snapshot

These are the original routed Backplane KiCad 10.99.0-bp.4 files, retained for
provenance. The working project one directory up is its validated KiCad 9 export
and is authoritative for this repository. The downgrade removes only footprint
gate-swap unit metadata, with no pad, net or copper changes. Do not edit both
copies independently or regenerate placement/routing over the finished board.
